# 0.4.0 Plugin Check対応と配布候補

## 修正の判断

- 管理画面GETはWordPressのスラッシュを解除し、文字列型と完全一致の許可形式で検証する。読取り専用フィルターにnonceを要求しない理由を当該行へ記載。不正な値を別の有効IDへ正規化しない。
- 設定POSTは既存の権限・全フィールド型・nonce・CAS検証を維持し、リダイレクトには同じ検証済みの入力を使用。REQUEST_METHODの型と入力処理も明示。
- 描画バッファは固定HTMLと個別にエスケープした値だけを含む。途中で台帳が変化した場合に破棄する目的を保持し、出力行の限定的な例外理由を明記。フォームを壊す全体エスケープは行わない。
- cleanupのfopen/fcloseはflock/fstat/stream hashに必要。unlinkは検証済みの同じパスと戻り値を使う必要がある。フィルターで削除先を変更できるwp_delete_fileや、ローカル記述子を提供しないWP_Filesystemへの置換はしない。対象sniffだけに理由を付記し、root・owner・mode・inode・manifest hash・削除前台帳を引き続き検証。
- CIのチェック対象や失敗基準を除外・緩和していない。

公開済み0.3.0と共通部品PR #1は変更しない。旧0.4.0 ZIPと既存検証結果も履歴として保持する。最終候補の検証結果は別JSONへ記録する。
